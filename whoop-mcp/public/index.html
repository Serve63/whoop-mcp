Hoe het werkt

De connector bundelt de WHOOP API in gebruiksklare tools voor het Model Context Protocol.

1

OAuth machtigen

Meld je aan met je WHOOP account via de Start OAuth knop. De tokens worden veilig lokaal opgeslagen.

2

Connector toevoegen

Ga in ChatGPT naar Instellingen → Connectors en voeg de URL van deze server toe als MCP endpoint.

3

Data ophalen

Gebruik de tools hieronder om recente recovery-, slaap- en workoutgegevens in je gesprek te laden.

Beschikbare tools

whoop_today_summary

Krijg in één oproep een overzicht van je herstel en de laatste slaapscore.

whoop_recovery_range

Vraag herstelmetingen op tussen een begin- en einddatum in ISO-formaat.

whoop_sleep_range

Ontvang slaapactiviteiten, inclusief duur en slaapfasen, over de gevraagde periode.

whoop_workouts_range

Bekijk workouts met intensiteit, duur en strain binnen een opgegeven tijdvenster.

Installatie & configuratie

Gebruik deze gids om de server op een platform zoals Vercel, Render of je eigen Node host te deployen.

  1. Maak een WHOOP Developer applicatie aan en noteer de Client ID & Secret.
  2. Stel de redirect URI in naar https://<jouw-host>/oauth/callback.
  3. Deploy dit project en vul de omgevingsvariabelen in.
  4. Open /oauth/login om tokens op te slaan en verbind daarna via ChatGPT.

.env voorbeeld

WHOOP_CLIENT_ID=<client-id>
WHOOP_CLIENT_SECRET=<client-secret>
WHOOP_REDIRECT_URI=https://<jouw-host>/oauth/callback
WHOOP_SCOPES=read:recovery read:sleep read:workout read:cycles read:profile
TOKEN_STORE_FILE=./tokens.json
PORT=3000

Pas de waarden aan voor jouw omgeving. Voor meerdere gebruikers is een externe geheime opslag aan te raden.
